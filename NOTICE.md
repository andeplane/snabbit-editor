The original game artwork and level data in game-resources/ come from Snabbit,
using a snapshot from andeplane/snabbit. Original per-level credits are preserved
in the bundled JSON. The two lever-state sprites under World/Switches/ were
created with built-in ImageGen from the original artwork and the user-selected
Chunky Lever concept on 2026-10-25.

This repository contains the editor and the resources it previews, rather than
the native game source or private repository history.
